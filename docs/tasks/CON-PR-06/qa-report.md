# CON-PR-06 QA 결과

## 로컬 브라우저 QA

- Chromium desktop 1440×900 및 mobile 390×844에서 새 관계 편집과 대화 도식 흐름을 검증했다.
- 사용자가 관계를 저장하기 전에는 도식 전환이 없고, 저장 후에는 양쪽 관계와 설계 revision이 함께 바뀐다.
- 대화 요약은 목록으로 시작하며, 도식으로 바꾼 뒤 저장 관계와 각 결정의 원본 대화 이동을 확인했다. 압축된 메시지는 기존 reveal 동작으로 표시된다.
- 관계가 저장되지 않은 상태에서는 텍스트 요약이 유지되고 모바일 화면에 도식 전환이 없다.
- 직접 영향받은 설계 준비 반응형 inspector 회귀도 8/8 browser tests 안에서 통과했다.

## Preview QA

PR Preview가 생성된 뒤 URL과 배포 commit SHA가 확정된 HEAD와 일치하는지 확인하고, 결정론적 테스트 세션으로 같은 desktop/mobile 흐름을 재실행해 결과와 캡처를 추가한다.
