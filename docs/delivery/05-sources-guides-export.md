# 5단계 — 자료, 설정 가이드와 내보내기

## 목표와 사용자 결과

사용자가 TXT, Markdown과 텍스트 PDF를 참고 자료로 사용하고 설계 항목의 근거를 확인한다. Agent는 확정 설계에 맞춘 설정 가이드 전체를 생성하며, 사용자는 세 문서를 각각 Markdown으로 복사하거나 다운로드한다.

## 연결 기준

- 화면 설계: [홈·프로젝트·파일](../ui/05-home-projects-and-files.md), [문서 작업 공간](../ui/04-document-workspace.md), [문서·설정 가이드 청사진](../ui/screens/05-documents-and-guide.md)

- 요구사항: `SRC-001`, `SRC-002`, `DOC-007`, `EXP-001`, `NFR-004`
- 결정: `DEC-005`, `DEC-008`, `DEC-009`, `DEC-013`, `DEC-016`, `DEC-020`
- 선행 조건: source item 연결과 GeneratedDocument framework 완료
- 차단 gate: 추출 텍스트 수정 정책, 설정 가이드 완료 필수 여부

## 작업 단위

### SRC-501 파일 선택과 제한

허용:

- `.txt`
- `.md`, `.markdown`
- 텍스트 레이어가 있는 `.pdf`

제한:

- 파일당 10MB
- 프로젝트당 최대 5개
- OCR 미지원

화면:

- 허용 형식과 제한을 선택 전에 표시한다.
- 각 파일에 이름, 크기, queued/extracting/ready/unsupported/failed를 표시한다.
- 파일마다 민감정보 제거 안내를 표시한다.

성공 조건:

- 크기와 개수는 추출 전에 검증한다.
- 확장자와 MIME이 모순되면 실패 처리한다.
- 실패한 파일 때문에 성공한 파일이 제거되지 않는다.

### SRC-502 텍스트 추출

구현:

- TXT/Markdown은 인코딩 오류를 탐지해 텍스트로 읽는다.
- PDF는 문단의 읽기 순서를 우선하고 표 셀은 일반 텍스트로 평탄화한다.
- 추출 텍스트, preview와 hash를 저장하고 원본 바이너리 장기 보관을 보장하지 않는다.

성공 조건:

- 텍스트가 없는 PDF를 unsupported로 표시한다.
- 표 레이아웃이 보존된 것처럼 표시하지 않는다.
- 추출 실패 원문 예외를 사용자에게 노출하지 않는다.
- 추출 텍스트 편집 여부는 결정 gate 확정 전 read-only preview로 제한한다.

### SRC-503 근거 연결과 자료 제거

구현:

- 파일에서 나온 proposal에 source ID, 발췌와 위치를 연결한다.
- 사용자가 설계 항목에서 근거 preview를 열 수 있게 한다.
- 자료 제거 전 영향받는 근거 수를 표시한다.

성공 조건:

- ready 자료의 필요한 발췌만 Agent 요청에 포함한다.
- 파일 제거 후 설계 항목을 삭제하지 않고 `근거 없음` 상태로 표시한다.
- 원문 전체가 로그에 기록되지 않는다.

### GDE-504 설정 가이드 전체 생성

입력:

- confirmed technical decision
- 운영·배포·보안 제약
- 관련 source excerpt
- 프로젝트의 확정 요구사항과 PRD

출력:

- 사전 조건
- 설치 순서와 명령
- 환경 변수 이름과 보관 원칙
- 외부 서비스 연결
- 실행·검증 방법
- 실패 시 확인 사항
- 보안 주의사항

성공 조건:

- Agent가 전체 문서를 새로 작성한다.
- 기존 `docs/guide` 링크 모음으로 대체하지 않는다.
- 요구사항이나 PRD의 기술 결정을 임의로 변경하지 않는다.
- 사용자 승인 전 `draft`로 표시한다.
- 명령·버전은 확정 기술 결정과 업로드된 source excerpt에서 근거를 찾을 수 있는 내용만 작성한다(`DEC-041`).
- 가이드 본문 상단에 "실행 전 최신 버전과 명령어를 직접 확인하라"는 고정 면책 문구를 포함한다.
- 근거 없는 버전·명령을 추측해 작성하지 않는다. 근거가 부족하면 해당 항목을 오픈 이슈로 표시한다.

### EXP-505 복사와 Markdown 다운로드

대상:

- 요구사항명세서
- PRD
- 설정 가이드

구현:

- 현재 선택 문서의 전체 Markdown 복사와 개별 다운로드를 제공한다.
- 파일명은 정제된 프로젝트명과 문서 유형을 포함한다.
- Object URL은 다운로드 후 해제한다.

성공 조건:

- ZIP과 전체 묶음 행동을 제공하지 않는다.
- Markdown에 버튼, modal, 상태 배지 같은 화면 제어 문구가 포함되지 않는다.
- 코드 fence, 목록, 표와 한글이 다시 열었을 때 유지된다.
- 복사 실패 시 수동 선택 가능한 대체 행동을 제공한다.

## 필수 테스트

1. 허용 확장자와 MIME 조합
2. 10MB 경계와 5개/6개 경계
3. TXT 인코딩, Markdown, 텍스트 PDF와 이미지 PDF
4. PDF 표 평탄화 fixture
5. 파일별 일부 성공·일부 실패
6. 근거 preview와 자료 제거 영향
7. 프로젝트별 최초 AI 안내와 파일별 민감정보 안내
8. 설정 가이드 schema 오류와 생성 실패
9. 세 문서 각각 복사·다운로드
10. 안전한 파일명과 Object URL 해제

## 완료 증거

- 파일 fixture 목록과 추출 결과
- 제한·MIME 계약 테스트
- 근거 연결/제거 테스트
- 설정 가이드 정상·오류 fixture
- 다운로드된 Markdown 샘플 검증 결과
- 업로드와 설정 가이드 모바일 캡처

## 단계 종료 조건

지원 자료가 안전하게 추출·연결되고 설정 가이드가 확정 설계에서 생성되어야 한다. 세 문서를 개별 Markdown으로 내보낼 수 있으며 파일 원문과 비밀 정보가 로그에 남지 않아야 한다.
